# Release gates (current v1.5.0)

See shared `lean-workflow.md` and `review-pass-contract.md`. Final QA expects **three grouped reports** (`learning`, `editorial`, `fidelity`) and one course-level consistency review completed after editorial and before final fidelity. Run `shared/scripts/run_quality_gates.py --phase final`, `scripts/aggregate_reports.py --enforce-three-passes` and `shared/scripts/audit_course_coverage.py --strict` with current project paths.

The Fidelity gate is critical and may not be skipped: full `source-catalog.json`, `course-coverage-contract.json`, per-Word fidelity ledger, independent claim/topic review, actual source excerpts and current SHA-256 for the Word and sources. Later Word changes invalidate it. The Content QA 27-ID register is audited on every resource; keep full original PPTX and index but inspect only relevant slides on demand. Format, stock evidence, notes, assets, hyperlinks and all-page render must pass separately. A machine-only pass never substitutes for semantic or visual review. No incomplete control is integral green.
