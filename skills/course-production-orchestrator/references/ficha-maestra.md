# Ficha Maestra del Curso

La Ficha Maestra es el contrato común para productores y revisores. Completarla antes de producir.

## Campos obligatorios

| Campo | Definición |
|---|---|
| Nombre del curso | Nombre oficial del proyecto. |
| Cliente / marca | Cliente y marca aplicable. |
| Objetivo general | Resultado observable esperado al finalizar. |
| Audiencia | Rol, experiencia, contexto y nivel técnico. |
| Contexto de uso | Dónde/cómo se tomará: móvil, oficina, planta, piso de venta, etc. |
| Plataforma final | Rise, Storyline, Genially, video, LMS u otra. |
| Tono | Formal, cercano, técnico, transaccional, motivador, institucional, etc. |
| Persona lingüística | Tú, usted, nosotros o impersonal. |
| Narrativa | Sin historia, storytelling ligero, historia continua, role play u otra. |
| Personajes | Nombre, rol, personalidad funcional y relación. Usar N/A si no aplica. |
| Rol del participante | Qué hace el participante dentro del aprendizaje: decide, asesora, opera, observa, etc. |
| Nivel de adaptación | 0 Literal, 1 Sintetizar, 2 Reorganizar, 3 Contextualizar, 4 Enriquecer. |
| Duración total | Tiempo objetivo o límite. |
| Número de recursos | Estructura ya aprobada. |
| Tipos de recursos | Video, lectura, interactivo, descargable, evaluación, etc. |
| Duración por recurso | Límites por tipo. |
| Nivel de interacción | Bajo, medio o alto; describir propósito. |
| Estrategia visual | Stock, diagramas, gráficos, íconos, personajes, screenshots permitidos/prohibidos. |
| Política de stock | Proveedor, IA permitida/no permitida, links y forma de citar. |
| Evaluación | Tipo, cantidad de reactivos, formatos, retroalimentación y criterio de aprobación si aplica. |
| Reglas de redacción | Guía interna, glosarios, términos permitidos/prohibidos, tú/usted, etc. |
| Entregable | Word en plantilla oficial por recurso, salvo instrucción distinta. |
| Corrección automática | Qué errores objetivos puede corregir el sistema. |
| Escalamiento humano | Qué cambios requieren aprobación. |
| Criterio de éxito | Qué significa que el curso está listo para entrega. |

## Regla de bloqueo

No producir si falta alguno de estos mínimos: objetivo, audiencia, fuentes, tono, narrativa, plataforma, estructura/número de recursos o nivel de adaptación.

## Notas de narrativa

Definir la narrativa una sola vez para todo el curso. Si existe historia continua, registrar:

- Situación inicial.
- Personajes y roles.
- Mecánica recurrente.
- Cómo conecta un recurso con el siguiente.
- Qué no debe cambiar entre recursos.

## Campos contractuales de Word (v1.3)

- **Orientación del guion:** A4 vertical salvo aprobación explícita de horizontal.
- **Cabecera:** solo un bloque de metadatos al inicio del documento; sin repetir en saltos.
- **Cuerpo:** únicamente Notas de Edición/recomendaciones y Contenido del Recurso.
- **Trazabilidad:** `qa/R##_trazabilidad.md`, manifest y reportes externos al Word. Nunca trasladar `Fuente:`, `Slides de referencia:` o datos de QA al guion.


## Contrato de tratamiento visual (v1.3.1)

Declarar proveedores de stock permitidos, si deben excluirse imágenes IA, densidad orientativa y estilo. En Rise, si el recurso elige Tabs/Accordion, pedir propuesta visual por ítem o justificación pedagógica de alternativa. En video, indicar si hay talento y tipos de apoyo autorizados (plecas, pop ups, big captions, B-roll, stock-video real enlazado, mapas mentales, pirámides, procesos, comparativos, interfaces). La elección específica corresponde al recurso y su narración; **nunca imponer todos los elementos ni stock a todos los recursos**. Consultar `shared/references/visual-language-and-stock-policy.md`.
