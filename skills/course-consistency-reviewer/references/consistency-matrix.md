# Matriz sugerida de consistencia

Crear una fila por elemento recurrente:

| Elemento | Valor aprobado | Recursos donde aparece | Variantes encontradas | Acción |
|---|---|---|---|---|
| Personaje | Alex - asesor | R1,R3,R5 | asesor/vendedor | Unificar según ficha |
| Término | Listas Negras | R6,R10 | lista negra | Unificar |

No crear un término “mejor” si el cliente ya fijó uno.
