# Rúbrica de dinamismo

Puntuar 0-2 por criterio:

| Criterio | 0 | 1 | 2 |
|---|---|---|---|
| Densidad | Muro de texto / escena saturada | Mixto | Fragmentación clara |
| Variedad | Un solo formato | 2 formatos repetidos | Mezcla útil y coherente |
| Propósito | Interacción decorativa | Parcial | Cada interacción tiene función |
| Ritmo | Monótono o acelerado | Aceptable | Fluido y natural |
| Continuidad | Bloques aislados | Conexiones débiles | Transiciones claras |
| Participación | Pasivo | Preguntas ocasionales | Decisiones/práctica relevante |
| Sincronía visual | Visual genérico/no relacionado | Relación parcial | Visual refuerza el concepto o acción exacta |

Interpretación orientativa: 12-14 VERDE, 8-11 AMARILLO, 0-7 ROJO. No usar la suma para ignorar un hallazgo crítico.

## Interpretación para Rise y video v1.3.1

Variedad alta no significa cantidad alta de stock. En Tabs/Accordion, juzgar si cada ítem dispone de visual útil o alternativa razonada. En video, diversidad ponderada entre talento, plecas, pop ups, big captions, stock/B-roll, diagramas o interfaces; escoger por el tipo de información. Sincronía visual exige momento narrativo y contenido visible; un stock irrelevante no mejora el puntaje.
